# Voice Project Hub

PROMPT GLOBAL — APPLICATION VOICE OFF SCHOOL

Je veux créer une application web professionnelle appelée VOICE OFF, appartenant à VOICE OFF SCHOOL.

L'objectif de l'application est de permettre à des clients de commander facilement des services de voice-over professionnels pour différents types de projets.

L'application doit avoir une interface moderne, premium, simple, fluide et responsive, adaptée au desktop, à la tablette et au mobile.

1. IDENTITÉ VISUELLE

La charte graphique principale doit utiliser uniquement trois couleurs principales :

Jaune : couleur d'accent principale, utilisée pour les boutons principaux, CTA, éléments actifs et certains détails visuels.

Noir : couleur principale pour les textes importants, certains fonds, titres et éléments forts de l'interface.

Blanc : couleur de fond principale et pour créer de l'espace et de la lisibilité.

Le design doit être moderne, élégant, professionnel et orienté audiovisuel.

Éviter une interface trop chargée.

Utiliser :

beaucoup d'espace blanc ;

une typographie moderne et lisible ;

des cartes avec des coins légèrement arrondis ;

des boutons très visibles ;

des animations légères ;

des transitions fluides ;

une hiérarchie visuelle claire.

Le jaune doit être utilisé comme élément de contraste et non comme couleur de fond dominante sur toute l'application.

7. CRÉATION DU SCRIPT

Créer une interface avec deux choix :

OPTION 2 — JE N'AI PAS ENCORE DE SCRIPT

Afficher un assistant IA / chatbot.

29. ARCHITECTURE TECHNIQUE

Utiliser une architecture moderne et maintenable.

Utiliser :

Préparer l'architecture pour une intégration avec une IA permettant de générer les scripts.

Ne pas mettre de clés API directement dans le frontend.

Les secrets et clés API doivent être stockés côté serveur / variables d'environnement.

30. IMPORTANT — LOGIQUE MÉTIER

Ne pas considérer les styles, catégories et voice-over comme des données statiques.

Ils doivent être récupérés depuis la base de données.

Le workflow doit être :

Admin crée catégorie → Admin crée styles → Admin crée voice-over → Admin associe les styles/catégories → Client voit uniquement les options disponibles.

Le système doit donc être piloté par les données du back-office.
